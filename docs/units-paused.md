# 暫停工作紀錄單位功能

2026-09-14，依使用者「單位請先停用」要求生效，優先於先前數量必須搭配單位的規格。

- 員工表格／展開明細隱藏 uom、item_stock_uom、item_conversion_factor；主管結果不顯示單位欄。
- 物料搜尋只顯示代碼及品名，不再带入單位。保存仍驗證物料存在、啟用及非範本，保留品名快照。
- 取消數量配單位的必填規則與物料單位匹配／換算驗證。數量維持非負、有限數值，工時規則與審核鎖定不變。
- 不刪既有 uom 資料，不改 ERPNext Item/UOM 主檔或庫存；舊欄位留在資料庫。這是工作紀錄功能暫停，不是禁用 ERPNext 全站 UOM。
- 目前未定義跨物料數量合計或單位換算，不能把無單位數量當作庫存數量。

scripts/test_units_disabled_poc.py 驗證數量 5／0 無單位可存、選物料不帶單位、已有合法單位值保存後保留、可送審、欄位 hidden；物料與審核回歸測試 PASS。测试交易 rollback。前端由使用者手動驗收。

手動驗收：先保存輸入再重新載入；新增一列，填工作、數量 5、工時 1、結果，不需填單位即可保存。選物料亦不應出現單位要求；主管查詢不再顯示單位欄。請回報保存及畫面結果。

恢復單位功能需同時調整 schema 顯示、前端帶入與後端驗證，並處理停用期間無單位的記錄；不可只打開欄位就視為恢復完成。
