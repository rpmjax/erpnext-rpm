## 來源問題與處理

- 一位來源 Employee 未填 User：保持未綁定，不根據姓名或員工號猜配。後續需提供正確對照，或確認不需登入。
- 一組員工號重複（兩筆）：若依員工號去重會合併不同 Employee。核對失敗的匯入未提交；修正為來源 Employee ID 對照不同本地 ID 後，33 筆均獨立保留。
- 重複員工號原值仍保留，尚未由業務確認更正；不宣稱來源資料已全部清理完畢。
- 一位員工無 Reports To，保持來源值；尚未判定是否為預期最高主管。
- 未匯入公司財務科目對照、銀行／健康／護照等非本輪必要資料，也未複製原站安全金鑰、社交登入資料或管理員角色。
- User 歡迎郵件停用，使用新產生的本地測試密碼；建立帳號不代表已完成 Guest Browser 登入驗收。
