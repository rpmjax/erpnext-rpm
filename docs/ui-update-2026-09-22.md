## Hyper-V 更新提示

以 paskadmin 執行，逐條執行，任何失敗立即停止。先確認工作目錄乾淨及備份離機副本：

```bash
cd ~/src/erpnext-rpm
export RPM_STATE_DIR=/home/paskadmin/.config/rpm-worklog-vm
git status --short
bash deploy/deploy.sh backup
git fetch origin codex/work-target-phase1
git switch --detach 8ec3d73
git log -1 --oneline
bash deploy/deploy.sh build
bash deploy/deploy.sh update
bash deploy/deploy.sh status
```

git status 有修改時先處理，不 reset。update 必須成功跑完 migrate，才能同步 Client Script。不要 configure/init。更新後 Ctrl+Shift+R，驗收桌面入口及重整、物料選取與保存、手機卡片新增/編輯、右欄切換及原審核流程。此為可選更新指示，本次沒有連線修改 VM；GCP 不在本次更新範圍。
