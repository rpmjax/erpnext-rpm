# 物料關聯第一版：需求、實作與驗收

使用者已同意「自行填寫優先＋選填物料搜尋」，並要求紀錄與開發。已部署本地 rpm_worklog App；自動驗證 PASS，瀏覽器由使用者手動驗收。

## 已確認範圍

- Work Item 保持必填自由文字，不強迫每件工作建立物料。
- 每列另存選填 Link Item。搜尋顯示代碼、品名、庫存單位；最多 20 筆，支援代碼／品名關鍵字。無匹配仍可自由填寫，不自動建立 Item。
- 選取後僅在工作內容／單位空白時帶入，既有輸入不覆蓋。明細顯示關聯代碼與選取時品名。
- 可解除關聯，清除物料快照與換算資訊，保留工作內容、原單位及數量；後者仍受既有數量／單位規則約束。
- 保存時驗證 Item 存在、啟用且不是品項範本（需選具體 variant），單位須為 stock_uom 或該 Item 合法正數換算單位。不自動轉換使用者填寫的完成數量。
- 同一關聯後續保存保留資料庫中的品名快照，主檔改名與 API 偽造快照均不覆蓋歷史名稱；改選其他代碼時重取新品名。解除後再重新選取並保存，視為重新關聯。
- 單位／換算係數以保存當下主檔驗證；不是庫存交易快照。物料停用後，含此物料的草稿需解除或重新選取才能再次保存／送審。
- 待審／核准仍鎖定整張，包括物料關聯；退回後可修改。主管明細新增關聯代碼與品名。
- 不產生 Stock Entry，不開放物料主檔維護、價格、庫存數量或廣泛 Item 讀取。搜尋為獨立受角色及有效員工驗證的 API，僅回傳白名單三欄。

## 實作

App items.py 負責搜尋與伺服器驗證；item_picker.js 提供工作列明細中的 Search Item／Remove Item Link。setup.install 新增子表欄位及 Client Script，擴充既有主管 API 欄位白名單；舊工作單沒有自動猜配物料。繁體中文常用字串加入 zh-TW.csv。

備份前綴 20260911_160217-frontend，存於 site private/backups。Docker image 重建並更新應用容器，原站未動。這是第一版獨立搜尋對話框，沒有將自由文字欄改成強制 Link，也尚未提供規格、條碼、模糊拼字或歷史常用排行。

## 測試結果

scripts/test_items_poc.py 在 rollback 交易內驗證：選填連結、文字保留、單位带入、不合法單位拒絕、快照防偽與主檔改名後保留、解除關聯、送審後不可改物料、停用品不出現在搜尋、Guest 拒絕。審核與資料規則回歸測試 PASS。

獨立員工 HTTP 登入：搜尋 200，僅回傳 name/item_name/stock_uom；原 Item GET 403，Guest 拒絕。登入頁 200。未代使用者操作瀏覽器。

站台原有可用 Item 數為 0，因此僅新增一筆非庫存合成測試品 RPM-POC-SHOCK，名稱「PoC 後避震器（搜尋測試）」、單位 PoC Piece。不是正式品料，也沒有入庫或領料。

## 手動驗收

1. 先保存目前尚未保存的輸入，再 Ctrl+Shift+R。以試辦員工開啟草稿工作紀錄。
2. 在工作列右側點鉛筆／展開明細，找「搜尋物料／Search Item」。
3. 輸入 RPM-POC 或「後避震器」，應列出 RPM-POC-SHOCK。點選後，應見關聯代碼與品名；原本空白的工作內容／單位帶入。
4. 若原先已填「檢查外觀」，再次選取時此文字應保留。工時填合理值、數量依需求填，保存並重開核對。
5. 按「解除物料關聯」，代碼／品名清除，但工作文字／單位保留；仍可保存為非物料工作。
6. 重新關聯，改成該 Item 未設定的單位，保存應拒絕並提示調整或解除關聯。
7. 送審後嘗試改關聯，應受既有鎖定限制；主管查詢展開可看見該物料。不要為測試核准正式內容，請使用測試單。

回報搜尋按鈕、結果挑選、自動帶入、解除與保存是否正常。下一階段的物料報表、製令連結與庫存整合須另定範圍。
